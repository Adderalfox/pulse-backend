# Project Overview: Pulse Backend (AI HR Intelligence)

Your project is an AI-powered HR intelligence system built with Scala (Play Framework), using PostgreSQL (via Slick) for structured data and Qdrant for vector-based search.

## Core Flow (Your Main Goal)
1. **Data Capture**: Employees appreciate each other (stored in Postgres + embedded in Qdrant).
2. **Intelligence**: The `AwardRecommendationService` uses an Agentic Loop (via Gemini) to analyze those appreciations, build a profile summary, and match them against `AwardDefinitions` stored in Qdrant.
3. **Delivery**: The `NominationService` then takes those matches and generates a high-quality "Nomination Draft" that explains why the employee deserves the award based on specific evidence.
